Investigating memory systems for LLM agents and the "dreaming" concept, this research found that the term actually encompasses three unrelated approaches: scheduled memory maintenance (as in OpenClaw and Claude Code Auto Dream), inference-scaling through pre-computation (Letta's sleep-time compute with 5x fewer tokens), and neuroscience-inspired techniques like HippoRAG. Key findings show that full-context baselines outperform RAG-based memory systems below ~150 conversations (70–82% vs 30–45% accuracy), memory update operations remain critically weak across production systems (best case 65%, most under 25%), and consolidation systems require careful separation of selection from synthesis to avoid promoting noise into permanent stores. The research provides an [evaluation checklist](evaluation-checklist.md) and [systems comparison table](systems-comparison.csv) for designing memory systems, with practical recommendations favoring append-only storage with supersession pointers, provenance filtering, and measuring against a full-context baseline first.

- "Dreaming" conflates scheduling maintenance, scaling inference, and neuroscience metaphors—only one has strong empirical support
- Full context wins on accuracy and cost below ~150 conversations; update correctness is the unsolved problem
- Scoring gates alone promote verbatim noise; consolidation requires separate generation step ([OpenClaw #67363](https://github.com/openclaw/openclaw/issues/67363))
- Append-only with validity windows and supersession pointers sidestep the field's worst-measured operation
